## 〜OSMを用いた学生・社会人向け作業スペース共有サイト〜
# 「Spot share map」の作成と利用情報の拡充

## 中間構想発表時点での概要
本研究では、東京・神奈川のビジネス街や人口密集エリアを中心に、カフェやファストフード店、コワーキングスペースなどに設置されたスマートフォンやPCの充電用コンセントについて情報共有できるウェブサイトを、OpenStreetMap（OSM）を用いて運用することを目標とした。既存の充電マップでは把握できない「充電可能な席の位置」「店内の雰囲気」「混雑時間帯」といった詳細な情報について情報共有できる機能や、ユーザー全員がスポットを登録できる機能、アカウント作成によるお気に入り登録機能などのオリジナリティを追加した(Claudeとcodexを併用)。なお、自分自身でも複数月にわたりフィールドワークを実施し、充電可能な店舗や作業用スペースを記録・分析する。現地での調査結果はピンや説明付きで保管できて(Firebaseを利用)、誰もが自由に共有できる地理空間情報として公開した。本研究は、より細かい実地調査や機能性によって既存データを補完するとともに、データの充実を通じて、外出先で充電場所を必要とする社会人や学生の利便性向上に貢献することを目指す。

## 1.	Introduction
1 背景

外出先での充電コンセント探しは、多くの学生・社会人にとって日常的な悩みである。カフェやファストフード店の一部には充電可能な席が用意されているが、どの店舗のどの席で充電できるのか、実際に座ってみるまで分からないことが多い。また、就職活動時に面接やWebテスト受験のためコワーキングスペースを利用した際、充電器の有無に加えて、静かで集中できる環境なのか、話して良いスペースがあるかなどを口コミサイトなどで調べるのが面倒だった。そこで、充電や勉強、面接に最適なスペースをユーザー参加型で共有できるウェブサイトを作成した。

既存の充電マップやDENGENCAFEには、利用者自身が現地でスポットの登録や具体的な情報の書き込みがてきる「シェア要素」星やコメントを付けられる「口コミ要素」はない。参加型にすることで、充電可能な座席や雰囲気などの情報も付け加えられ、継続的に蓄積される地理空間情報として扱える価値になると考えた。そこで本研究では、OSMをベースマップとし、ユーザー全員で情報共有できる「Spot Share Map」を開発・運用する。

2 初代バージョン

初代バージョンは、以下のような機能を持つプロトタイプとして公開した。

・OSMによる地図表示

・現地調査結果の投稿フォーム（店舗名、最寄り駅、徒歩分数、カテゴリ、営業時間、現地調査メモ）

・カフェ・喫茶店／無料スペース／図書館／コワーキング／その他のカテゴリのみの分類

・最寄り駅名での検索

・地図をタップしてピンを置く方式の位置登録

3 初代からの主な変更点

| 項目 | 変更前 | 変更後 / 内容 |
| :--- | :--- | :--- |
| **位置登録** | 無反応バグ | 駅名を入れても無反応であったバグを修正 |
| **検索方法** | 最寄り駅名 | 駅名・店名の両方に対応 |
| **投稿項目** | 簡易チェック | 無料／Wi-Fi／電源の簡易チェックに加え、オンライン面接・Web会議OKなど利用シーン別の項目 |
| **営業時間** | 自由に入力 | 24時間営業かチェック＋時刻ピッカーによる構造化入力 |
| **評価機能** | 現地調査メモ | 口コミをユーザーが自由に投稿・削除できる機能に変更 |
| **デザイン** | 紺色のみ | 3色のテーマとオリジナルキャラクターを採用 |
| **利用状況** | 確認不可能 | ユーザーの利用状況に関する分析サイトを公開 |

改良版では、他の利用者にも使ってもらうことを前提に、投稿のしやすさや情報の信頼性（編集・削除の仕組み）、継続的な利用を促す仕組み（お気に入り、通知）を重視して機能を見直している。

4 研究目的

本研究の目的は、OSMを用いた充電・作業スペース共有サイト「Spot Share Map」を開発・運用し、実際のフィールドワークによって現地情報を蓄積しながら、利用者が投稿・検索・比較しやすいサイトへと改善していくことである。なお、既存の充電マップでは扱われていない機能の拡充を通じて、外出先で充電場所や作業スペースを探す学生・社会人の利便性向上に貢献することを目指す。

5 現時点での課題

・参加型の地図サービスとして、どのように共有すれば新規のユーザーを獲得できるか。

・現地調査によって得られる情報や口コミは、利用者の店舗選びに本当に影響するのか。

・どのような機能を追加することができれば、継続的に利用してもらえるサイトに成長するのか。

## 2.	Method
1 システム概要

Spot Share Mapは、ClaudeとCodex、Firebaseで、OSMをベースマップとして利用して作成している。

| 番号 | ツール名 | 用途・役割 |
| :---: | :--- | :--- |
| 1 | **Claude / Codex** | コード生成 |
| 2 | **Firebase** | 投稿データの保存 |
| 3 | **OpenStreetMap** | 地図 |
| 4 | **GitHub Pages** | サイト公開 |

コードの生成にはClaudeとCodexを併用している。最初の作成から、現在の機能追加や不具合の相談まで、チャット形式でClaude、Codexに投げ、改善案や実装コードを受け取りながら、自身の動作確認や提案も繰り返しながらより良いサイトにしていく予定だ。

※Claude＝Claude Sonnet 4.6,2026-6~(未定)

※Codex＝GPT-5.3-Codex,2026-6~(未定)

2 主要となる機能

右手にある「場所を登録」ボタンより新規スポットを追加することが可能。完成された投稿は、地図上にピンとして表示され、カテゴリや徒歩分数、お気に入り登録の有無で絞り込み、ユーザー全員が検索できる。

3 現地調査

自分以外のユーザーが新規スポットの登録が完了した通知がiCloudメールで届くように設定している。そのため、自分自身で店舗やスペースに足を運んだり、口コミサイトを見るなどして、充電可能な席の有無やWi-Fi環境、混雑状況が正しいか確認する。また、不適切な口コミやスポットの登録がなされた場合の削除申請・通報ボタンや、免責事項についての説明欄も設定してある。

4 分析・可視化

サイトの利用状況を把握するため、投稿された総スポット数や日々の訪問者数などを表示する分析用のウェブサイトを別途公開している。（Spot share map 公式 | アナリティクス）これにより、自分自身が運用状況を把握できるだけでなく、SNSでの告知を通じてユーザーにも活動の広がりや貢献度を示せるようにしている。

## 3.	Results
【中間発表時点での進捗】

2026年8月時点では、初代版の公開後、検索・投稿フォーム・編集削除・デザイン・アカウント機能について、自分自身の使用感を踏まえた改善を継続的に行っている。

投稿フォームには、無料利用可否・Wi-Fiの有無・電源の有無に加えて、オンライン面接やWeb会議に利用できるかどうかのチェック項目を新たに追加した。これは、充電・作業スペースとしての利用だけでなく、就職活動や在宅勤務に関連する利用シーンも想定した項目である。営業時間の入力についても、自由記述のテキストから、24時間営業のチェックボックスと開始・終了時刻を指定する形式に変更し、入力のばらつきを減らした。

広報・フィードバック収集としては、公式Xアカウントを開設し、サイトの使い方を4コマ形式でまとめた案内画像や、機能追加のお知らせを発信している。学生が運用していることを明示し、改善点などをDMで受け付ける体制をとることで、利用者からフィードバックを得られるようにしているが、そもそも新規ユーザーやフォロワーが増えないという大きな課題にぶつかっている。

## 4.	Discussion
1 現地調査の意義

既存の充電マップやWi-Fiマップは、店舗単位での「電源あり」「Wi-Fiあり」といった情報にとどまることが多く、実際に座ってみないと分からない席の位置や混雑状況までは扱っていない。本研究では、現地に足を運ぶことによって、どこに充電器があるかという所まで把握できるようなサイトにすること、参加型でスポットや口コミの投稿、星５段階の評価ができることなど、既存サービスでは得にくい実用的な情報を蓄積できると考えられる。

2 現在の課題 

・投稿データの信頼性を保ちながら、誰でも編集・削除できる仕組みをどこまで許容するか検討中である。

・口コミの投稿など、不適切なコメントへの対応方針をより確りと定める必要がある。

・ユーザー参加型のサイトであるため、投稿数が少ない段階では地図上の情報が偏っている。今後、投稿データの蓄積とともに、新しいユーザーや長く利用して下さるユーザーの獲得方法を考えていく必要がある。

## 5.	Conclusion
1 最終的な目標

卒業論文の最終ゴールは、以下の3点とする。

	1. 継続的に投稿・検索・利用されるサイトの運用

	2. フィールドワークによる情報の蓄積

	3. 利用状況の分析と改善を続ける


2 今後の作業

今後は、現地調査によるスポット投稿と並行して、投稿データの信頼性確保、ユーザーの確保、SNSでの発信などを進める。また、蓄積したデータや見えてきた課題を分析・改善しながら卒業論文としてまとめていく。
